# Trabajo #1 - Vision por computadora 2025-2

## P5 -  Implementar técnicas fundamentales de segmentación de imágenes
### Requisitos

- Python 3.9+ (probado con 3.10/3.11)
- OpenCV (cv2)
- NumPy
- Matplotlib

### Ejecucion
- Abre P5-Segmentacion.ipynb en Jupyter/VSCode.
- Ajusta la ruta a la imagen (../Images_P5/Escena.jpg o relativa a tu entorno).
- Ejecuta todas las celdas: verás máscaras, segmentaciones y el conteo/área en consola.
